## Decisiones registradas

- **Fuente de tokens de color**: las variables CSS de
  `docs/frontend/diseno/hurioscan-claude-design.html`. Confirmado por el
  Coordinador (2026-08-18) tras verificar que ningún ADR de `docs/decisiones/`
  contiene colores (la referencia del README del diseño está rota; la corrige
  Coordinación en un lote de gobernanza aparte). `prototipo.html` no tiene
  autoridad visual.
- **Solo tema claro**: aprobada por Kevin, 2026-08-18, vía Coordinador. F00
  tokeniza únicamente la paleta clara del diseño; el tema oscuro queda fuera
  del horizonte y sería trabajo planificado aparte.
- **Tailwind CSS v4**: los tokens se declaran con `@theme` en
  `resources/css/app.css`; no existe `tailwind.config.js` en v4. La
  "configuración de Tailwind" de F00-UT-01 se materializa ahí (interpretación
  trivial documentada, validada por el Coordinador).
- **Tipografía del diseño**: `Archivo` (sans) e `IBM Plex Mono` (mono),
  extraídas del design HTML. Se cargan con el plugin de fuentes de
  `laravel-vite-plugin` (bunny) ya presente en `vite.config.js`, reemplazando
  la `Instrument Sans` del scaffold.
- **Menú lateral y rutas**: los enlaces consumen rutas **por nombre** y se
  protegen con `Route::has()` — un nombre aún no declarado se muestra
  deshabilitado en lugar de romper. La línea frontend no edita
  `routes/web.php`.
