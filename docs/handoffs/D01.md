## Observaciones no bloqueantes

Ninguna incumple una fuente aprobada; quedan como mantenimiento a decidir.

1. El rojo real se demostró para el paso Tests; Lint y Build quedan cubiertos por inferencia estructural (misma shell, sin `continue-on-error` ni `if:`).
2. D01-UT-03 no muestra mejora de duración (35 s contra 36 s) — esperable con dependencias pequeñas; la reutilización está probada por los mensajes de restauración, no por el tiempo.
3. SEG-01: acciones de terceros fijadas por tag mayor en vez de SHA. Riesgo teórico de cadena de suministro; severidad baja en un repositorio académico sin secretos ni despliegue. Ninguna fuente aprobada exige fijación por SHA. Propietario sugerido: `devops`.
4. SEG-02: `permissions:` no declarado, hereda el default del repositorio. Endurecerlo a `contents: read` sería buena práctica; el RFC no lo exige.
5. `actions/cache@v4`, `actions/setup-node@v4` y `pnpm/action-setup@v4` declaran Node 20 (deprecado) y GitHub ya los fuerza a Node 24. No rompe nada hoy; decidir el salto de major en un mantenimiento futuro.
